# 05 — 分层上下文组装（L1/L2/L3）

**What to build:** 每位 Agent 发言前按固定顺序组装上下文：系统提示（角色蓝图 + 角色特性）→ 静态设定（按注入项）→ L3 全讨论要点 + 作者指令 → L2 最近 20 条滚动摘要 → L1 最近 5 条完整消息 → 触发消息原文；按模型窗口控制预算、超限降级摘要粒度；发言附带「回应的是哪条消息 / 哪位成员」的引用，让讨论脉络可溯。
