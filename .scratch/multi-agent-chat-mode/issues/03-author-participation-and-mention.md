**What to build:** 作者作为群成员随时发送消息：消息实时并行插入、不阻塞当前 Agent 生成，并在下一个发言权窗口被优先处理；支持 @角色名 定向召唤（被 @ 者 +100 强意愿加成，下轮大概率由被 @ 者发言）；前端支持点击成员列表快速 @；作者发言计入讨论历史与上下文，后续 Agent 会承接作者意见。
