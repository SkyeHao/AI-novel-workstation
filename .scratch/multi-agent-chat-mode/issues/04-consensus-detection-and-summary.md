# 04 — 共识检测与合成者总结

**What to build:** 讨论接近共识时系统提前预警，给作者补充机会；以三路信号判定共识：关键词信号（「我同意 / 一致 / 达成共识」等）+ 观点收敛（先降级，06 接入向量聚类）+ Agent 自评（每次发言附带 consensus 字段）；连续 2 轮加权超阈值触发合成，由合成者产出结构化总结（核心共识 / 主要分歧 / 综合方案 / 行动建议），过程与结果分区展示；作者可随时手动终止讨论。

## Answer

已完成。

- 后端：新增 `backend/src/workflow/consensus_detector.ts` 共识检测器——三路信号加权（关键词 0.6 + Agent 自评 0.7 + 观点收敛 0.75），level = min(1, Σ)，连续 2 轮超阈值（≥0.7）触发合成；观点收敛默认降级为「最近窗口内 ≥2 位不同成员表态一致」（跨成员，避免单条发言重复计权），预留 convergenceFn 接缝供工单 06 接入向量聚类。
- 集成：ChatSession 在每次 Agent 发言后评估共识，接近共识（≥0.6 未触发）时推送 `consensus` 预警事件（仅一次）；达成共识后进入 synthesizing，由「合成者」成员基于讨论记录产出结构化总结（核心共识 / 主要分歧 / 综合方案 / 行动建议），`done` 事件携带 summary；无合成者成员时不触发合成并重置检测器继续讨论。
- Agent 发言 prompt 要求结尾输出【共识度：0~1】自评；检测用原文，上屏前剥离自评行（stripSelfRating）。
- 手动终止：状态进入 terminated，不产出伪总结；中止（abort）不再误报 error 事件。
- 测试：新增 5 例黑盒断言——连续两轮达成共识触发合成且 done 带 summary、仅一轮不触发、无合成者不触发、接近共识推送预警、手动终止不产出伪总结。chat_session.test.ts 共 20 例全部通过。
