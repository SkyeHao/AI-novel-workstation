# 04 — 共识检测与合成者总结

**What to build:** 讨论接近共识时系统提前预警，给作者补充机会；以三路信号判定共识：关键词信号（「我同意 / 一致 / 达成共识」等）+ 观点收敛（先降级，06 接入向量聚类）+ Agent 自评（每次发言附带 consensus 字段）；连续 2 轮加权超阈值触发合成，由合成者产出结构化总结（核心共识 / 主要分歧 / 综合方案 / 行动建议），过程与结果分区展示；作者可随时手动终止讨论。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 三路信号各自触发与组合触发均正确（黑盒断言），触发前推送共识预警。
- [ ] 达成共识后合成者产出结构化总结，过程记录与最终方案分离展示。
- [ ] 作者手动终止在任何状态可用，且不产出伪总结。
- [ ] 关键词信号与 Agent 自评在无向量库时也能独立触发收敛（降级路径）。
