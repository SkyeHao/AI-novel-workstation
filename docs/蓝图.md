## 1. 产品定位

**AI 小说工作站**是一个面向"有一定计算机基础的用户"的前端优先 Web 应用，通过 AI 辅助完成长篇网络小说（20 万~500 万字量级）创作。

核心原则：
- **人主导 + AI 辅助**：AI 负责扩展、执行、检查与建议；创意与决策权始终在作者手中
- **前端优先**：用户全程只与前端界面交互，不接触命令行、不接触数据文件
- **数据与代码分离**：创作数据存于仓库外的作品库目录（`PROJECT_DIR`），代码与数据不混存
- **本地单机**：唯一外部依赖为 LLM API 调用，无云服务、无账号体系

## 2. 创作流程总览

```
IDEATION 确认核心要素 → 设定生成与编辑 → 前置检测 → 逐章正文 → 阅读页修改 → 审阅/去 AI 味
     （对话）          （设定中心）      （正文页）    （正文页）    （阅读页）      （审阅页）
```

六个产品入口（导航）：

| # | 页面 | 功能 | 对应 PRD 阶段 |
|---|---|---|---|
| 1 | 工作台 | 项目列表、新建/切换/归档小说项目 | 阶段1 |
| 2 | IDEATION | 给 IDEA，Agent 对话确认核心要素 | 阶段1 |
| 3 | 设定中心 | 世界观 / 人物卡片（卡片墙）/ 分级大纲，可编辑 | 阶段2~3 |
| 4 | 正文页 | 前置设定完备检测 → 手动逐章生成 | 阶段4 |
| 5 | 阅读页 | 读正文 + 选段 Agent 对话修改 | 阶段4 |
| 6 | 审阅 / 去 AI 味 | 手动触发的质量处理，逐章可回溯 | 阶段5 |
| 7 | 配置页（次级） | 模型池、任务分配、搜索设置、连接测试 | 基础设施 |

## 3. 页面详设

### 3.1 工作台（项目列表）

- 展示全部小说项目卡片：封面/书名、状态（IDEATION/设定中/写作中/审阅中）、进度（已写章节数/目标章节数）、最近更新
- 操作：新建项目、切换进入、归档
- 新建项目流程：输入项目名 + 一句话核心梗 → 进入 IDEATION

### 3.2 IDEATION 对话页

- 产品形态：AI 对话界面（流式输出），作者给 IDEA，Agent 逐步扩展并**提问确认**核心要素
- 核心要素四件套：**主线、愿景、风格、世界观**（见 CONTEXT.md 术语）
- Agent 通过 `ask_user` 提问，作者回答；循环直至要素齐备
- 要素齐备后，作者点击"生成设定"→ 触发设定中心生成
- 数据：会话记录持久化，可中断恢复

### 3.3 设定中心

三个标签页，全部为**结构化 JSON 存储 + 双视图（卡片/表单编辑 + Markdown 预览）**：

**世界观**
- 表单/卡片视图：时代背景、世界规则、地理地图、阵营关系等分区块
- 字段级修改

**人物卡片（卡片墙）**
- **可点击的卡片组件**：正面为人物姓名 + 一句话特征 + 角色定位（主角/配角/反派）
- 点击展开：性格、目标、缺陷、金手指等结构字段（字段级可编辑）
- 可新增卡片、删除卡片、拖拽排序
- 人物关系图（轻量呈现，第一版可做"关联人物标签"）

**分级大纲**
- 四级大纲：总纲 → 卷纲 → 篇章纲 → 章纲（可折叠树形展示）
- 可增删卷/篇章/章，调整顺序，字段级编辑（核心事件、功能定位、出场角色、伏笔）

### 3.4 正文页

- **前置设定完备检测**（入口拦截）：AI 对照必要设定清单检测，缺什么明确提示补齐（跳转设定中心），补齐前禁止生成
- **手动逐章触发**：作者点"生成下一章"，单章生成，完成后回到当前章
- 章节列表：已生成章节可点击进入阅读页
- 生成过程展示：Agent 状态步骤（组装上下文→生成→校验→沉淀记忆）

### 3.5 阅读页

- 沉浸式阅读：正文排版、章节切换、字数/进度展示
- **选段修改**：选中一段文字 → "与 AI 对话修改" → Agent 改写该段 → **预览对比（原文/改写）** → 作者确认应用或还原
- 仅修改选中段落，其余正文不动
- 可发起整章"审阅 / 去 AI 味"入口

### 3.6 审阅 / 去 AI 味页

- 手动触发，可对某章或某几章批量发起
- 结果：审阅报告（结构/节奏/逻辑/代入感等维度）+ 去 AI 味改写建议
- 每项可预览对比、应用/放弃；逐章可回溯历史处理记录

### 3.7 配置页（次级入口，保留现有能力）

- 模型池 CRUD、任务分配（text/structure/check）、连接测试、项目目录、搜索配置
- **通用聊天调试能力保留于此**（不再是主导航产品功能）

## 4. 数据模型

### 4.1 项目目录规范（数据与代码分离）

```
{PROJECT_DIR}/
├── {项目名}/
│   ├── project.json          # 项目元数据（状态、目标字数、平台、绑定文风）
│   ├── ideation/
│   │   └── sessions/         # IDEATION 会话记录
│   ├── settings/
│   │   ├── worldview.json     # 世界观（结构化）
│   │   ├── characters.json    # 人物卡片（结构化）
│   │   ├── outline.json       # 四级大纲（结构化）
│   │   └── style.json         # 风格配置
│   ├── chapters/
│   │   ├── {n}.md             # 章节正文（含元数据 frontmatter）
│   │   └── ...
│   ├── memory/
│   │   ├── facts.jsonl        # 原子事实（append-only）
│   │   ├── progression.jsonl  # 能力进阶轨迹
│   │   └── summaries/         # 分层摘要（L1 单章 → L5 全书）
│   └── review/
│       └── {chapter}.md       # 审阅/去AI味记录
```

### 4.2 核心实体

- **Project**：id、name、status、target_words、platform、created_at
- **CharacterCard**：id、name、role(主角/配角/反派)、personality、goal、flaw、golden_finger、relations[]
- **Worldview**：sections{ era, rules, geography, factions, history }
- **OutlineNode**：层级总纲/卷/篇章/章，含核心事件、功能定位、出场角色、伏笔
- **Chapter**：no、title、status(PENDING/GENERATED/FINALIZED/REVIEWED)、content_md
- **Fact / Progression**：append-only 记忆账本条目

### 4.3 章节状态机

```
PENDING → GENERATED → FINALIZED → REVIEWED
              │            │
              └─修改后重新 GENERATED
```

## 5. Agent 设计

- **底座**：沿用现有 ReAct agent + 工具系统（web_search / file_read / file_write / ask_user），保留 LLM 层全部能力
- **角色分工**（同一 agent 骨架，不同 system prompt）：
  - IDEATION agent：确认核心要素
  - 设定生成 agent：产出结构化设定
  - 正文写作 agent：逐章生成
  - 修改 agent：阅读页选段改写
  - 审阅 agent：审阅与去 AI 味
- **上下文策略**（Q6-C，轻量实现）：
  - 全文记忆：本地分层摘要（L1 单章 → L5 全书），按需注入
  - 按需加载：写作时组装"章纲 + 前 2 章 + 出场角色档案 + 相关世界观片段 + 活跃伏笔"
  - **不上向量库/图数据库**，用本地文件 + 关键词召回 + 摘要实现第一版
- **前置检测**：AI 对照必要设定清单检查，缺项明确提示补齐，未齐备拦截生成

## 6. 技术方向

- **保留**：FastAPI 后端、Vue3 + Element Plus 前端、LLM 层（client/manager/models/exceptions）、ReAct agent、工具系统、交互记录存储
- **移除/降级**：chat-tester 主导航入口（能力并入配置页）
- **重写**：业务层路由与前端业务页面（按本蓝图）
- **明确不做**：Qdrant、Neo4j、LangGraph、分叉写作、批量并行写作（第一版）

## 7. 里程碑路线图

### M1 — 工作台 + IDEATION + 设定中心
项目模型与目录规范、项目列表页、IDEATION 对话页、设定中心三标签（世界观/人物卡片/大纲）、结构化存储与编辑

### M2 — 正文生成 + 阅读页
前置设定完备检测、手动逐章生成、章节落盘、阅读页、选段 Agent 修改（预览对比）

### M3 — 审阅/去 AI 味 + 打磨
审阅页、去 AI 味流程、配置页整合、产品级 UI 打磨、整体集成测试

### M4 — 记忆系统增强（可选演进）
分层摘要、正典账本、按需加载的上下文组装精化
