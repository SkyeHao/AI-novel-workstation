# 重绘：保留底座、重写业务层

现有文档（PRD/架构/详细设计/路线图）承诺了重型基建（Qdrant、Neo4j、LangGraph、分叉写作、L0~L5 摘要），而实际代码偏向"LLM 客户端测试器 + 阶段1 聊天工具"。经与用户质询确认，**流程骨架正确、重型基建过度、业务层缺失**。

决定：以用户真实预期重绘项目为"小说工作站"——前端驱动的创作流程（IDEA 对话确认核心要素 → 设定生成与编辑 → 前置检测 → 逐章正文 → 阅读页 Agent 修改 → 审阅去 AI 味）。保留已验证的底座（FastAPI + Vue3 + LLM 层 + ReAct/工具系统，61 测试全绿），砍掉 chat-tester 气质功能与重型基建，重写业务层与缺失页面。记忆系统用本地文件 + 分层摘要的轻量实现，不上 Qdrant/Neo4j。
