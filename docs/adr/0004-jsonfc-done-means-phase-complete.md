# jsonfc 协议 done=true 语义：从"全部完成"改为"本阶段完成"

jsonfc 协议中 `done=true` 不再表示"整个创意共创彻底完成、会话结束"，而是"当前阶段已完成"，由前端据此渲染下一步操作卡片（是否生成愿景文档、是否继续生成设定等）。

原因：创意共创是分阶段推进的流程——要素确认完不等于全部结束，作者需要逐个拍板"下一步做什么"（Q6-C 采用前端 UI 卡片而非把询问塞进对话流）。若 done 保持"全部完成"语义，Agent 无法表达"本阶段完成、请作者决策下一步"，流程衔接会断裂。

代价：done 的语义从"会话结束标志"重定义为"阶段边界标志"，需同步调整 prompts 中 done 的定义与前端"完成"提示，IDEATION 会话的结束判定不再由单次 done 决定。
