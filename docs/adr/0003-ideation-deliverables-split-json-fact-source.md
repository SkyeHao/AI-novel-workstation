# 创意共创交付件拆分：核心要素 JSON 为唯一事实源，愿景文档为展示层

创意共创不再产出单一 `故事愿景文档.md`，而是两个交付件：项目根 `核心要素.json`（结构化 JSON，唯一事实源）与 `故事愿景文档.md`（给人读的展示层）。

原因：单文件 markdown 作为事实源脆弱——设定生成需"读 markdown 再解析"，模型输出截断或格式损坏会导致信息丢失（曾发生愿景文档缺失会话中已确认的要素）。核心要素（主线/愿景/风格/世界观）由 Agent 经 ask_user 与作者逐个确认后直接写入 `核心要素.json`，作为设定生成等下游环节的唯一输入依据；愿景文档由 Agent 基于 JSON 展开，补充市场分析、人物框架、分卷节奏等展示内容，事实以 JSON 为准。

本决策使"人主导"更扎实：作者拍板的决策以结构化数据固定下来，不随展示层内容漂移。
