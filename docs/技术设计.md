│ Agent 层   │ 工具系统    │ 工作流编排         │

## 2. 存储层设计

### 2.1 作品库目录（数据与代码分离）

`PROJECT_DIR`（.env 配置）为唯一沙箱根，所有 agent 文件操作强制限制其内。

```
{PROJECT_DIR}/{项目名}/
├── project.json            # 元数据
├── ideation/sessions/*.json
├── settings/{worldview,characters,outline,style}.json
├── chapters/{no}.md        # 含 frontmatter 元数据
├── memory/
│   ├── facts.jsonl         # append-only
│   ├── progression.jsonl   # append-only
│   └── summaries/L1..L5.jsonl
└── review/{chapter}.md
```

### 2.2 存储抽象

- `storage/project_store.py`：项目 CRUD、目录初始化、列表/切换
- `storage/settings_store.py`：四类设定的 JSON 读写、字段级更新
- `storage/chapter_store.py`：章节读写、状态机推进
- `storage/memory_store.py`：facts/progression append-only、摘要读写
- `storage/path_safety.py`：`resolve_project_path` 强制 `resolve()` 后校验 `relative_to(project_dir)`（修复现有逃逸漏洞）

所有写操作经由统一入口，避免 agent 直接操作文件系统。

## 3. 数据模型

```jsonc
// project.json
{
  "id": "uuid", "name": "书名", "status": "ideation|setting|writing|reviewing",
  "target_words": 2000000, "platform": "fanqie|qidian", "created_at": "ISO"
}

// settings/worldview.json
{ "sections": { "era": "...", "rules": "...", "geography": "...", "factions": "...", "history": "..." } }

// settings/characters.json
{ "characters": [
  { "id": "c1", "name": "林动", "role": "protagonist",
    "personality": "...", "goal": "...", "flaw": "...", "golden_finger": "...",
    "relations": [{"target": "c2", "type": "死仇"}], "updated_at": "ISO" }
]}

// settings/outline.json
{ "root": { "type": "total", "summary_short": "...", "summary_long": "...",
  "children": [ { "type": "volume", "name": "第一卷", "task": "...", "target_words": 500000,
    "children": [ { "type": "arc", "name": "...",
      "children": [ { "type": "chapter", "no": 1, "event": "...", "function": "铺垫",
        "cast": ["c1"], "foreshadow_plant": ["..."], "foreshadow_reap": ["..."] } ] } ] } ] } }

// chapters/{no}.md frontmatter
// ---\n no: 1\ntitle: ...\nstatus: pending|generated|finalized|reviewed\n...

// memory/facts.jsonl
{"ts":"ISO","fact":"...","source":"ch:1","known_by":["c1"]}
```

章节状态机：`PENDING → GENERATED → FINALIZED → REVIEWED`，修改后回 `GENERATED`。

## 4. API 路由设计

| 方法 | 路径 | 功能 |
|---|---|---|
| GET/POST | `/api/projects` | 项目列表 / 新建 |
| GET/PUT/DELETE | `/api/projects/{id}` | 项目详情/更新/归档 |
| POST | `/api/projects/{id}/ideation/start` | 开始 IDEATION 会话 |
| GET/POST | `/api/projects/{id}/ideation/sessions` | 会话列表/新建 |
| POST | `/api/projects/{id}/ideation/sessions/{sid}/message` | 发送消息（SSE） |
| POST | `/api/projects/{id}/ideation/sessions/{sid}/answer` | 回答 ask_user |
| POST | `/api/projects/{id}/ideation/sessions/{sid}/generate-settings` | 生成三类设定 |
| GET/PUT | `/api/projects/{id}/settings/{worldview|characters|outline|style}` | 设定读/改 |
| GET | `/api/projects/{id}/prereq-check` | 前置设定完备检测 |
| POST | `/api/projects/{id}/chapters/{no}/generate` | 生成章节（SSE） |
| GET | `/api/projects/{id}/chapters` | 章节列表 |
| GET | `/api/projects/{id}/chapters/{no}` | 章节内容 |
| POST | `/api/projects/{id}/chapters/{no}/revise` | 选段修改（SSE，段落级） |
| POST | `/api/projects/{id}/chapters/{no}/review` | 审阅/去AI味（SSE） |
| GET | `/api/projects/{id}/memory` | 记忆查看 |

保留现有：`/api/config/*`（模型/分配/搜索）、`/api/chat`（调试）、`/api/interactions`。

## 5. Agent 设计

- **骨架**：沿用 `ReActAgent` + `ToolManager`；本轮激活原生 function_call 支持（现有死代码），DSML 保留为兜底
- **5 角色 prompt**（`workflow/prompts.py` 拆分）：
  1. `IDEATION_PROMPT`：扩展 IDEA，用 ask_user 逐步确认主线/愿景/风格/世界观
  2. `SETTINGS_PROMPT`：按已确认要素产出三类结构化设定（JSON）
  3. `WRITE_PROMPT`：按章纲 + 上下文组装写单章正文
  4. `REVISE_PROMPT`：阅读页选段改写（只动选中段）
  5. `REVIEW_PROMPT`：审阅 + 去 AI 味
- **上下文组装**（轻量）：写作时注入"章纲 + 前 2 章正文 + 出场角色档案 + 相关世界观片段 + 活跃伏笔"。第一版用关键词召回设定 JSON 片段 + L1 摘要，不做向量检索
- **前置检测**：AI 对照必要设定清单检查，返回缺项清单；未齐备时正文生成接口 403 拦截
- **确认机制**：设定生成、章节修改均产"待确认"草稿 → 前端预览对比 → 作者确认后才写入正式文件

## 8. 关键约束

- **沙箱**：所有 agent 文件操作限制在 `PROJECT_DIR` 内（`resolve()` + `relative_to` 校验）
- **本地监听**：默认 `127.0.0.1`（当前 `restart-backend.ps1` 用 0.0.0.0，需改）
- **无重型基建**：不引入 Qdrant/Neo4j/消息队列
- **测试**：沿用 pytest + 假客户端策略；新增存储层与 API 路由测试
